# Build SYNRA — The Financial Grid

## Scope
Create the complete production-ready SYNRA website at all requested routes, using the original `synra.png` logo and `synban.png` banner without recreating or recoloring them.

## Implementation
1. **Foundation and assets**
   - Add the supplied logo and banner as direct static image assets and derive the favicon from the original logo.
   - Establish the obsidian, graphite, ivory, bronze, and champagne design tokens, typography, motion, focus states, and reduced-motion behavior.
   - Centralize official URLs and all product/module content so links and “COMING SOON” states stay consistent.

2. **Shared experience**
   - Build the sticky desktop navigation, animated full-screen mobile navigation, loading treatment, footer, external-link handling, and branded error/404 states.
   - Add per-route search and social metadata, canonical URLs, and SYNRA banner sharing metadata.

3. **Homepage**
   - Build the cinematic banner-led opening, status terminal, narrative typography, infrastructure explanation, financial-grid visualization, all five conceptual modules, ecosystem architecture, value pillars, six principles, Arc disclosure, token terminal, roadmap, X follow section, and complete footer flow.
   - Use lightweight CSS/SVG 2.5D visuals and purposeful motion so the homepage remains fast and does not initialize the full Grid experience.

4. **Interactive Grid**
   - Build `/grid` as a full-screen financial command-center visualization with a SYNRA core, PAY/FLOW/MARKET/VAULT nodes, outer value layers, orbital rails, routed data streams, node highlighting, contextual information, camera-like pointer movement, reset controls, and an optimized mobile layout.
   - Treat every animation as financial connectivity, not decorative particles or a game/metaverse experience.

5. **Documentation system**
   - Build the responsive three-column docs shell with collapsible mobile navigation and right-side table of contents.
   - Create every requested docs route with factual copy, diagrams, statuses, roadmap states, FAQ, disclaimer, changelog, Arc independence disclosure, and no fabricated token or market data.

6. **Quality verification**
   - Verify all routes, buttons, official links, mobile/desktop navigation, keyboard access, responsive layouts, no horizontal overflow, image integrity, metadata, reduced motion, and browser console behavior.
   - Confirm only X appears as social media and all unavailable financial information remains “COMING SOON.”
